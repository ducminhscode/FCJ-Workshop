# Báo cáo thực tập - FCJ Workshop

Dự án này chứa nội dung báo cáo thực tập được xây dựng bằng [Hugo](https://gohugo.io/), một framework tạo trang web tĩnh (Static Site Generator) nhanh chóng và mạnh mẽ.

## 📌 Yêu cầu hệ thống

Trước khi bắt đầu, hãy đảm bảo máy tính của bạn đã cài đặt:

* **Hugo (phiên bản v0.85.0)**
* **Git**

## 🚀 Hướng dẫn cài đặt và chạy website

### 1. Clone repository
Vì dự án có thể sử dụng các theme bên ngoài dưới dạng submodule, hãy dùng lệnh sau để tải đầy đủ:

```bash
git clone --recursive https://github.com/ducminhscode/FCJ-Workshop.git
cd FCJ-Workshop
cd internship-report
```

### 2. Chạy mô trường Devlopment

Để xem trước nội dung báo cáo trên trình duyệt, hãy chạy lệnh:

```bash
hugo server -D
```
Sau khi chạy lệnh, hãy truy cập: `http://localhost:1313/`
