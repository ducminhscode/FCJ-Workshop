### Week 1 Objectives:

- Get familiar with the internship environment at AWS First Cloud Journey (FCJ), understand the working process, task management, and progress reporting.
- Build foundational knowledge of Cloud Computing and service models (IaaS, PaaS, SaaS).
- Clearly understand the differences between On-premise and Cloud models, as well as the benefits of cloud computing.
- Successfully create and configure an AWS Free Tier account, ensuring compliance with security best practices (MFA, IAM).
- Get familiar with AWS Management Console and AWS CLI for resource management.
- Take initial steps in exploring AWS Global Infrastructure, cost optimization, and AWS Support.
- Learn Hugo to build a personal internship report website.
- Practice basic labs in Module 01 and apply knowledge in real scenarios.

### Week 1 Achievements:

- Familiarized with FCJ internship environment:
  - Understood workflow, task management, and progress reporting.
  - Clearly grasped training orientation and learning roadmap.
- Installed and configured working environment:
  - Installed Git and configured SSH with GitHub.
  - Installed VS Code and set up development environment.
  - Installed and configured AWS CLI.
  - Used SSH Client to connect to servers.
- Mastered Cloud Computing fundamentals:
  - Differentiated IaaS, PaaS, SaaS.
  - Understood differences between On-premise and Cloud models.
  - Learned key benefits: Scalability, High Availability, Cost Optimization.
- Set up and secured AWS account:
  - Successfully created and configured AWS Free Tier account.
  - Enabled MFA for root account.
  - Created Admin Group and Admin User following IAM security best practices.
- Worked with AWS Management Console and AWS CLI:
  - Practiced managing IAM.
  - Explored EC2 and S3.
  - Used Billing Dashboard and Support Center.
  - Successfully executed basic CLI commands to check and manage resources.
- Learned AWS Global Infrastructure:
  - Understood the concept of Region.
  - Understood Availability Zone (AZ).
  - Understood Edge Location.
  - Recognized how AWS deploys its global infrastructure.
- Practiced cost management and support:
  - Created AWS Budgets (Cost Budget).
  - Learned about Usage Budget, Reserved Instances Budget, Savings Plans Budget.
  - Created and managed Support Cases on AWS.
- Studied AWS Well-Architected Framework:
  - Understood 6 pillars: Operational Excellence, Security, Reliability, Performance Efficiency, Cost Optimization, Sustainability.
  - Began applying architectural best practices in system design thinking.
- Built internship report website using Hugo:
  - Installed Hugo.
  - Learned project structure (content, layouts, static, themes).
  - Customized menu and logo from theme.
  - Successfully ran static website on localhost.
- Practiced architecture design:
  - Used draw.io to design basic AWS architecture diagrams.
  - Gained initial understanding of cloud system deployment models.
