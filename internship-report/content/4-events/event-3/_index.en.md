# Summary Report "FCAJ HCM Knowledge Sharing"

## Event Objectives

The sharing session organized by the FCAJ team aimed to create a space where members could exchange ideas about learning methods, personal development mindsets and practical applications of knowledge in the fields of technology and Cloud Computing.

More than just a knowledge-sharing event, the session also helped participants better understand how individuals approach learning, problem-solving and mindset building while working in a rapidly evolving technology environment.

## Speakers

- **Khang Nguyen:** Solution Architect - Cloud Kinetics Vietnam
- **Thịnh Nguyễn:** DevOps/Cloud Engineer - First Cloud AI Journey
- **Nguyễn Phương Thảo:** GenAI Engineer - VIB
- **Hoàng Long:** Ambassador - First Cloud AI Journey

## Key Highlights

The sharing session revolved around four main topics, each offering a different perspective on learning, mindset and the practical application of technology.

### Session 1 - Personal Learning Methods

The first session focused on effective learning methods, building clear learning roadmaps and maintaining discipline throughout the learning process. The discussion emphasized that learning is not only about absorbing information but also about organizing knowledge systematically and practicing continuously.

### Session 2 - Automated Prompt Engineering & Advanced Prompting Techniques

The second session focused on prompt engineering optimization to improve the output quality of Large Language Models (LLMs). Several important techniques were introduced, including:
- **Chain-of-Thought (CoT):** Breaking down problems into step-by-step reasoning.
- **Self-Consistency:** Generating multiple reasoning paths and selecting the most reasonable result.
- **Tree-of-Thoughts (ToT):** Expanding multiple reasoning branches to evaluate different approaches.
- **Retrieval-Augmented Generation (RAG):** Integrating external data sources to improve accuracy and keep information up to date.
- **Role Prompting:** Assigning specific roles to AI systems to enhance context understanding and response quality.

Additionally, the AWS-based solution architecture demonstrated practical integration among API Gateway, Lambda, Cognito, Bedrock, DynamoDB and CloudWatch to build production-ready AI systems.

### Session 3 - Mindset in Learning and Applying Knowledge

The third session focused on long-term learning mindsets, transforming knowledge into practical capabilities and developing critical thinking when approaching problems. One key takeaway was that learning should always be connected with hands-on practice and continuous reflection.

### Session 4 - The BMAD Methodology

The final session introduced BMAD as an approach for optimizing workflows, decision-making and idea implementation. The content highlighted systematic thinking, analytical capability and the transformation of ideas into actionable steps.


## Key Takeaways

From the sharing session, several important lessons could be drawn:
- Gaining a clearer understanding of how to build learning strategies aligned with personal goals instead of learning randomly.
- Exploring modern prompt engineering techniques more deeply, especially CoT, ToT and RAG, which currently have significant practical value in AI-related fields.
- Recognizing the importance of mindset in knowledge acquisition and personal development.
- Understanding how to design scalable, secure and monitorable AI systems on AWS.
- Learning about BMAD as a framework that supports more logical work organization.

## Applying to Work

The knowledge gained from the event can be directly applied to both learning and professional work:
- Applying Chain-of-Thought and Role Prompting techniques to improve prompt quality when working with AI chatbots or RAG systems.
- Utilizing the RAG model to enhance the accuracy of consulting chatbots, especially in domain-specific data systems.
- Adopting structured learning methods to accelerate the process of learning new technologies such as Cloud Computing, AI Engineering and System Design.
- Using systematic thinking from BMAD to break down problems, prioritize tasks and optimize project implementation progress.
- Maintaining a continuous learning mindset to improve adaptability in rapidly changing technology environments.

## Event Experience

The event delivered a positive experience thanks to the diversity of perspectives shared by the speakers. Each presentation had its own unique style, ranging from technical insights to mindset discussions and real-world experiences.

One of the most remarkable aspects of the event was not only the professional knowledge shared but also the open and collaborative spirit among participants. The atmosphere encouraged discussion, interaction and active questioning.

The event also highlighted the value of community-based learning: knowledge expands much faster when people with shared goals, growth mindsets and a willingness to exchange practical experiences learn together.
