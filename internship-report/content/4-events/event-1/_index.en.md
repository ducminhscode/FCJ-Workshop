# Summary Report "AWS Perimeter Protection Workshop – Enhancing Security with CloudFront & WAF"

## Event Objectives

The **AWS Perimeter Protection Workshop** was organized to help engineers and developers gain a deeper understanding of how to build secure architectures for web applications on the AWS platform.
The event focused on introducing solutions to protect systems from increasingly sophisticated cyber threats such as DDoS attacks, bot traffic, and common web application vulnerabilities.

Through presentations and hands-on sessions, participants had the opportunity to learn about key AWS security services such as [Amazon CloudFront](https://aws.amazon.com/vi/cloudfront/), [AWS WAF](https://aws.amazon.com/vi/waf/) and [AWS Shield](https://aws.amazon.com/vi/shield/), and understand how to implement a defense-in-depth security architecture to protect internet-facing applications.

## Speakers

- **Nguyen Gia Hung** – Head of Solutions Architect - Viet Nam & Cambodia
- **Julian Ju** – Senior Edge Services Specialist Solutions Architect
- **Kevin Lim** – Senior Edge Services Specialist GTM

## Key Highlights

The event featured several in-depth sessions and practical workshops:

- **CDN Architecture with CloudFront:** Focusing on how to design a global content delivery architecture using CloudFront, optimize performance, and reduce load on origin systems.
- **Application Protection with AWS WAF:** Introducing how AWS WAF can be used to block malicious traffic, mitigate OWASP Top 10 vulnerabilities, and defend against bot attacks.
- **Hands-on Workshop:** Participants had the opportunity to practice configuring CloudFront, optimizing web application performance, and implementing security mechanisms using AWS WAF.
- **Analysis of Emerging Threats:** The workshop also highlighted the rapid increase in cyber threats, particularly the rise of DDoS attacks and AI-driven bot traffic.

## Key Takeaways

- A better understanding of how **CloudFront works from Edge to Origin** and how CDN helps reduce backend load.
- How to use **AWS WAF rules** to detect and block malicious requests.
- Best practices for **ordering WAF rules** to optimize both performance and security.
- Techniques for protecting applications against **DDoS** and **bot attacks**.
- Insights into new features such as **VPC Origin** and **Mutual TLS** in CloudFront.

## Applying to Work

- Deploy **CloudFront** to improve website performance and reduce the load on backend servers.
- Use **AWS WAF** to protect APIs and web applications from common web attacks.
- Implement **rate limiting** and **bot detection** to control abnormal traffic.
- Apply a **defense-in-depth** security model to enhance overall system security.
- Integrate monitoring tools such as CloudWatch to observe performance and detect potential incidents.

## Event Experience

The workshop was organized in a professional and engaging environment. The speakers shared many real-world experiences from production systems, helping participants better understand how AWS services are implemented and operated in practice.

The **hands-on lab** sessions were particularly valuable, allowing participants to directly configure CloudFront and AWS WAF while interacting with experts to discuss real-world scenarios.

In addition, the event provided a great opportunity for **networking** with cloud engineers and AWS enthusiasts, helping participants expand both their technical knowledge and professional connections.
